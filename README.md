# 🎙️ Transcriber Bot

Telegram-бот для распознавания речи, транскрибации видео/аудио и анализа контента через LLM.

## Возможности

- 🎤 Распознавание голосовых сообщений
- 🎵 Обработка аудио/видео файлов
- 🔗 Скачивание по ссылкам (YouTube, Instagram Reels и др.)
- 🧠 Анализ через LLM:
  - 📌 Главные мысли
  - 📝 Структурированный конспект
  - ❓ Вопросы с таймкодами
  - 🎧 Озвучка текста (TTS)
- 👑 Секретная админ-панель
- 💾 Кэширование результатов
- 🚦 Система лимитов для обычных пользователей

## Быстрый старт

1. Клонируй проект и перейди в папку
2. Создай `.env` по образцу `.env.example`
3. Запусти: `docker compose up -d`

## Настройка LLM-провайдера

Поддерживаются:
- `openrouter` (рекомендуется) — бесплатный агрегатор моделей
- `groq` — очень быстрый (может блокировать регионы)
- `openai` — платный, высокое качество
- `gemini` — Google (может быть недоступен в РФ)
- `none` — работа без LLM (кнопки показывают заглушку)

## Админ-панель

Отправь боту секретное слово (`ADMIN_SECRET`) в личку — откроется меню:
- 📊 Статистика
- 👑 Выдача PRO
- ⚙️ Текущие лимиты

## Лимиты

- Админ (`ADMIN_ID`): безлимит
- Обычные пользователи: 3 транскрипции/мес, до 15 мин
- После первой транскрипции: 24 часа PRO (безлимит)
